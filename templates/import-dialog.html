Format Texte : Collez un stat block Daggerheart ou du texte libre.

Le parseur détecte automatiquement les stat blocks Daggerheart et extrait les informations appropriées.

Format CSV : Première ligne = en-têtes, deuxième ligne = valeurs.

Colonnes supportées : name, hp, stress, evasion, description

Exemple : name,hp,stress,description
"Gobelin",5,2,"Un petit gobelin vicieux"

Format JSON : JSON d'acteur Foundry VTT complet.

Doit contenir au minimum les champs 'name' et 'type'.
